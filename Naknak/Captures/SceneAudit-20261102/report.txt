이번에 실제로 찾고 수정한 문제
1. T0 브로치 조사 판정
   브로치 앞 가구 때문에 가장 가까이 설 수 있는 위치에서 기존 조사 레이가 닿지 않았다.
   보이는 위치는 유지하고 BoxCollider2D의 아래쪽 조사 범위를 늘렸다.
   크기 (0.8,0.9) -> (0.8,1.4), 오프셋 (0,-0.4) -> (0,-0.65).
   플레이어 (-2,-2)에서 위쪽을 보고 실제 TryInteract 호출로 획득되는 것을 확인했다.
   이전 전체 스토리 검사는 CollectBrooch를 직접 호출하므로 이 문제를 검출하지 못했다.
2. 고정 배치 불일치
   T1에서 작은 항아리와 멀쩡한 도자기가 상하로 바뀐 배치를 바로잡았다.
   일부 씬에 빠진 오른쪽 작은 탁자와 진열대 타일, T1의 누락된 배경 타일을 맞췄다.
   가구의 깊이 정렬 기준도 위치와 맞췄다.
   전화기 사용, 도자기 파손 및 사건에 따른 아이템 변화는 유지했다.
3. 입력 시스템 중복
   S1 및 PrototypeScene에 남은 EventSystem을 비활성화했다.
   런타임 메뉴가 생성하는 하나의 EventSystem을 사용한다.
   수정 후 중복 경고 없이 메뉴 포인터 클릭이 옵션 페이지를 여는 것을 확인했다.

배치 검사
- TutorialSceneFlow의 14개 스토리 씬을 검사했다. 누락된 스크립트 0건.
- 그중 같은 골동품점을 표현하는 12개 씬의 타일 자산/월드 위치/변환을 비교했다.
- 수정 후 가구 그림 차이는 전화기와 도자기 상태 차이만 남았다.
- 조사 가능한 씬에서 전화기, 카운터 시계, 쓰레기통, 진열장, 기억 출구의 좌표는 일치했다.
- T0는 별도의 침실이고 프롤로그는 별도의 도입 씬이므로 골동품점과 같은 배치로 바꾸지 않았다.
- 컷신용 투명 충돌 타일과 NPC의 시간대별 위치 차이는 남아 있다. 모든 씬의 충돌/인물 배치가 완전히 같다는 뜻은 아니다.

수정 후 Play Mode 확인
- 전체 스토리의 정상 엔딩 도달, 증거 제시/반복 제시/잘못된 증거/취소, 현실 확인과 최종 상자 비교를 재검사했다.
- 14개 씬에서 메뉴/아이템/옵션/저장/로드 페이지 표시와 닫기 후 시간/위치 복원을 검사했다.
- T0 실제 획득 아이템 표시와 체크포인트 복원 후 메뉴도 검사했다.
- 전체 진행 및 메뉴 검사 285개 항목 PASS. runtime-result.txt에는 284개 세부 항목이 있고,
  검사 종료 시 Guarded가 수행하는 이동 샘플 존재 확인을 합쳐 285개다.
- T0에서 직접 걸어서 브로치 획득 -> 보석함 제시 취소 -> 브로치 포장 -> 메뉴 열기/닫기 -> 출구 -> T1 진입:
  별도 31개 항목 PASS. t0-native-result.txt 참조.
- T0 메뉴의 옵션 버튼을 PointerEventData로 클릭하여 옵션 페이지가 열리고 활성 EventSystem이 하나임을 확인했다.
- 마지막 실행 오류/경고 로그 0건. 플레이 모드를 종료했다.

접근 위치 검사
- approaches.txt에 씬별 대상 앞 접근 칸과 조사 방향을 기록했다.
- T2/T3/T4의 주요 조사 대상, 현실의 주요 대화 대상, 새 게임 T0의 브로치/보석함/출구에 접근 경로가 확인됐다.
- NO RAY APPROACH는 이 조사에서 레이 접근을 찾지 못했다는 뜻이다.
  컷신 중 숨긴 플레이어, 직접 조사하지 않는 진행 컨트롤러, 이미 획득해 비활성화된 아이템,
  연출용 인물도 포함돼 있다. 이것만으로 모든 항목을 게임 진행 오류로 판정하지 않았다.
- 새 게임 T0 브로치는 실패를 재현하고 판정 수정 후 실제 획득까지 재검증했다.

검증 범위
- 메뉴의 씬별 표시 검사는 전체 정상 진행과 별도다. 메뉴 검사용 씬에서는 연출 컨트롤러를 정지시켜
  다음 씬으로 자동 이동하는 간섭을 막고 페이지 표시를 직접 호출했다.
- 접근성 표는 충돌/레이 기하 검사다. 모든 대상의 모든 대사 분기까지 실제 호출한 것은 아니다.
- 이전 보고서의 2,160개 제시 순서 검사는 이번 배치 수정을 하기 전 결과다.
  이번 수정 후에는 전체 정상 진행과 씬별 메뉴, 접근성 및 T0 실제 조작을 재검사했다.
- 모든 키 입력 타이밍, 모든 저장 데이터, 모든 해상도 또는 빌드 환경의 무오류를 보장하는 검사는 아니다.

자연스러움에 대한 의견 — 수정하지 않음
- 브로치 분실 -> A/B 진술 검증 -> 주인의 행동 조사 -> 상자의 정전 전후 비교 -> 사건 해결은 인과가 연결된다.
- 후반 상자 비교를 위해 T2로 재진입한 뒤 주인의 감정/보석함 제시를 다시 거쳐 정전 시점으로 넘어가는 부분은 반복적으로 느껴질 수 있다.
- 시계 상자를 아이템 메뉴에서 조사해야 다음 단계로 이어진다. 목표 안내는 있지만 이를 놓치면 다음 행동을 찾는 데 시간이 걸릴 수 있다.
- 재현 시작점으로 즉시 옮겼다가 조사 대기 위치로 돌아오는 것은 현재 의도한 재현 방식이다.
  플레이어가 '과거 행동 재현'이라는 점을 놓치면 순간 이동처럼 느낄 여지는 있다.
- 위 항목은 코드와 정상 진행을 검토한 플레이 흐름에 대한 의견이다. 대사/연출/진행 구조를 변경하지 않았다.
