추가 반복 플레이 결과 - 2026-11-02 (Asia/Seoul)

결과: 검사한 시나리오 통과. 마지막 Unity 콘솔 Error 조회 0건. 플레이 모드 종료.

플레이 범위
- 메인메뉴 버튼으로 새 게임 시작 -> 정상 엔딩: 2회
- 각 플레이에서 추가 기억공간 왕복 4회, 합계 8회
- 첫 기억 진입, 조사 단계 재진입, 부분 재현 후 복귀, 재진입 후 진행 유지
- 전화기 반복 조사와 아이템 중복 여부
- 증거 선택 취소, 나가기 취소 후 계속 조사, 다시 나가기
- 기억공간 중간 저장 상태 복원 후 방문 횟수/아이템/조작 상태 확인
- 두 번째 새 게임의 방문 횟수 초기화
- 누적 증거로 정상 엔딩 도달

통과 수치
- 반복 플레이 검사: 412개 (반복된 검증과 이동 칸별 확인 포함)
- 일반 이동 경로: 152칸, NPC 이동 충돌: 1,314회 샘플
- 수정 후 카메라/메뉴/저장 검사: 49개
- 수정 후 앞뒤 표시 순서: 6개
- 합계: 467개 검증. 서로 다른 시나리오가 467개라는 의미는 아님.
- 안정된 T2 상태의 조사 대상 11개 모두 접근 가능한 조사 위치 존재

수정한 게임 문제
1. A가 전화기의 유일한 접근 칸을 막아 일반 이동/조사로 전화기 단서를 얻을 수 없었음.
   A의 전화기 대기 위치를 (-4,0)에서 (-4,1)로 조정.
   첫 방문/재방문 배치, T1/T2/T3/T4 설정과 경로 재생성 설정을 함께 수정.
   T2/T3/T4의 저장된 초기 위치도 맞춰 로딩 직후 위치 이동을 방지.
2. OneDrive 경로의 테스트 저장 파일을 교체할 때 Windows IOException 발생.
   파일 쓰기/이동/복사/교체 작업을 각각 제한적으로 재시도하도록 수정.
   전체 저장을 재시도하지 않아 재시도 때문에 저장 이력이 여러 번 회전하지 않도록 함.
   실제 배타적 파일 잠금을 해제한 뒤 저장 성공, 지속 실패 시 제한된 횟수 후 예외 전달 검증.

- 이전 방문에서 끝낸 대화와 이미 검증한 증거를 진행 상태에 맞게 처리

한계
MCP를 통한 스크립트 기반 Editor 플레이이며 사람이 모든 키 입력을 직접 누른 검사는 아님.
추가 왕복 구간은 텔레포트 없이 실제 이동/충돌/일반 조사 메서드를 사용.
일부 기존 스토리 검사에는 직접 상호작용 호출과 테스트 위치 배치가 포함됨.
모든 입력 타이밍, 모든 분기 조합, 모든 해상도/기기/빌드 환경을 완전 탐색한 것은 아님.
기존 사용자 저장 슬롯은 덮어쓰지 않았으며 파일 테스트는 별도 Captures 하위 폴더에서 수행.
